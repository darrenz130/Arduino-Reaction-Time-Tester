<h1>Arduino Reaction Time Tester PCB Design</h1>

<h2>Description</h2>

<p>
Designed and developed an Arduino-based reaction time testing system to measure human response speed with millisecond accuracy. The system uses two LEDs as visual stimuli, a push button for user input, and an LED display to show results. The firmware was written in C++ to handle timing, input detection, and randomized reaction prompts.
</p>

<p>
The circuit was first prototyped on a breadboard to validate functionality and identify timing and wiring issues. Through iterative testing and debugging, the design was refined for accuracy and reliability.
</p>

<p>
A custom PCB shield was then designed in KiCad to replace the breadboard setup, reducing wiring complexity and improving overall system stability and durability.
</p>



<h2>Languages and Utilities Used</h2>
- C++ <br>
- Arduino IDE <br>
- KiCad <br>
- Breadboard prototyping <br>
- Circuit testing and troubleshooting <br>
